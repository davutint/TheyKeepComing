# ZombieSlowTimerSystem - Editor Setup

## Kurulum

Ek sahne kurulumu gerekmez. `ZombieAuthoring` her zombi prefab'ina disabled `ZombieSlow` component'i bake eder.

## Kontrol

1. `NewGameScene` Play moduna gir.
2. Level-up panelinden `Frost Archer` kartini sec.
3. Frost ok isabet eden zombinin hareketinin kisa sureligine yavasladigini ve soguk/mavi tint aldigini dogrula.
4. Slow bitince tint normal beyaza donmeli.
5. Ayni hedefe tekrar Frost oku vurursa slow suresi yenilenmeli, stack ile kalici yavaslik olusmamalidir.

Script eklendikten sonra disaridan manuel compile komutu calistirma. Unity refresh sonrasi derlemeyi kendisi yapar.
